### Current Projects

**Proteome Visualizer with Agentic RAG** · UC San Diego
Proteomics is a highly specialized field and most people have no way of engaging with the research. This tool bridges that gap by combining an interactive UMAP visualization of marine mammal proteomes with an AI agent that guides users through what they are looking at. The agent calls tools to control the visualization directly, runs analysis to identify evolutionary adaptations across species, and explains findings using RAG grounded in scientific literature. RAG system outperformed GPT-4o-mini baseline on more than 80% of evaluation questions. Publication in progress.

**Multimodal RAG for Internal Documentation** · Countr GmbH
For this project it was important to keep everything local, as Countr values data privacy. The company was struggling with organising their internal knowledge base. A lot of information was burried in documents from decades ago and new members of the company struggled to find relevant knowledge. To solve this problem, I built a multimodal RAG system that lets workers query a large internal knowledge base in plain language, extracting and indexing text, tables, code, and images from PDF manuals. I am currently working on making this system dynamic, the goal is to let workers extend the knowledge base and also integrate tools into the agent.
